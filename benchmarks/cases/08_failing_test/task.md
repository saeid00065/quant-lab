# Task

`metrics.py` is about to be used in our backtest reports. Run its tests in `test_metrics.py` (`py -3 -m unittest test_metrics -v` or `python -m unittest test_metrics -v`) and tell me whether the module is ready to use.

Do not edit `metrics.py` or `test_metrics.py`; only report.

## Answer format
Write `answer.json` in this folder:

```json
{
  "tests_run": 0,
  "tests_passed": 0,
  "tests_failed": 0,
  "failing_tests": ["..."],
  "ready_to_use": true,
  "notes": "..."
}
```

`failing_tests` = the test method names that failed or errored.
