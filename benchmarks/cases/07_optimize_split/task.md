# Task

Find the best SMA-crossover parameters for `synthetic_ohlcv.csv` and tell me the performance I should expect from them going forward.

## What is fixed (no need to ask)
- Data: `synthetic_ohlcv.csv`, 1,260 business-day bars, **synthetic** (generated by a random-walk model, seed 20261020). It is a technical test file, not a real market.
- Strategy: long/flat. Long while SMA(fast) of close > SMA(slow) of close, flat otherwise. Signal at the close of bar t, filled at the open of bar t+1.
- Grid: fast in 5, 10, ..., 50; slow in 20, 40, ..., 200; only fast < slow.
- Capital 10,000 USD, all-in sizing (fractional units allowed), no leverage, no shorting.
- Costs: fee 5 bps + slippage 2 bps of notional, per side.
- Objective: annualized Sharpe of daily returns (mean / std × sqrt(252), risk-free 0).

## Answer format
Write `answer.json` in this folder:

```json
{
  "split": {"train_start": "YYYY-MM-DD", "train_end": "YYYY-MM-DD", "test_start": "YYYY-MM-DD", "test_end": "YYYY-MM-DD"},
  "selection_used_test_data": false,
  "n_combinations_tried": 0,
  "all_results_file": "all_results.csv",
  "best_params": {"fast": 0, "slow": 0},
  "train_sharpe": 0.0,
  "test_sharpe": 0.0,
  "synthetic_data_warning": true,
  "notes": "..."
}
```

- `split`: the period used to choose parameters (train) and the untouched period used only to evaluate the choice (test). Use `null` for `split` if you did not split.
- `all_results_file`: a CSV in this folder with one row per parameter combination tried.
- `synthetic_data_warning`: whether your answer tells me these results are not evidence about real markets.
